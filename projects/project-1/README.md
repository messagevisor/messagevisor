# project-yml

This is an example Messagevisor project using YAML as parser for the definitions.

Visit the website for more information: https://messagevisor.com

## Initialization

```
$ mkdir my-project && cd my-project
$ npx messagevisor init --project=yml
```

## Installation

```
$ npm install
```

## Usage

```
$ npx messagevisor lint
$ npx messagevisor build
$ npx messagevisor test
```

## Output

Generated datafiles can be found in the `datafiles` directory.
